# 치지직 채팅 퀴즈

스트리머 화면에 초성/그림을 띄우고, 시청자 채팅 단어로 채점한다.  
정적 페이지(GitHub Pages) + Cloudflare Worker(로그인·채팅 토큰).

한 페이지에서 방송 영역(위)과 조작(아래)을 같이 쓴다.  
OBS에는 위쪽 방송 영역만 크롭해서 넣으면 된다.

## 로컬

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

- 기본: http://127.0.0.1:4173/  
- 개발(가짜 채팅·남 채널): http://127.0.0.1:4173/?dev=1  

## 테스트

```bash
npm test
```

## Worker

로그인은 브라우저만으로 안 된다. Cloudflare Worker가 Client Secret으로 토큰을 교환한다.

1. [치지직 개발자 센터](https://developers.chzzk.naver.com/)에서 앱 생성  
2. **로그인 리디렉션 URL**  
   `https://chzzk-chat-quiz.web404dev.workers.dev/auth/callback`  
   (Worker 주소가 바뀌면 그에 맞게 수정)  
3. `worker/` 에서:

```bash
npx wrangler login
npx wrangler secret put CHZZK_CLIENT_ID
npx wrangler secret put CHZZK_CLIENT_SECRET
npx wrangler deploy
```

프론트의 Worker 주소는 `app.js`의 `WORKER_BASE`에 고정되어 있다.  
비밀값은 레포에 넣지 말고 `wrangler secret`만 쓴다.

## GitHub Pages (공개)

1. 이 폴더를 GitHub 레포에 올린다.  
2. Settings → Pages → Branch `main` / 저장소 루트.  
3. 배포 URL로 접속해 로그인·퀴즈를 진행한다.

## 문장 출처

뒤죽박죽 문장의 속담은 [위키낱말사전 분류:한국어 속담](https://ko.wiktionary.org/wiki/분류:한국어_속담)(CC BY-SA 4.0), 명언과 한국 영화 대사는 [위키인용집](https://ko.wikiquote.org/)(CC BY-SA 4.0)에서(코드에 적힌 한국 영화 명대사 12개도 함께 쓴다), 애니·드라마 명대사와 한국 영화 유명 대사는 `sentence-bank.js` 의 유명 대사 목록(`CURATED_LINES`, 영화는 같은 영화 2개까지)에서, 말한 사람 사진은 한국어 위키백과 대표 그림(위키미디어 공용)에서, 없으면 그 위키인용집 문서에 연결된 위키데이터 사진에서 받는다. 문장은 3어절 이상, 섞이는 글자(띄어쓰기·문장부호 빼고) 20자 이하만 쓴다. 명언은 말한 사람의 위키인용집 분류 이름으로 연예·음악·스포츠·과학·역사·정치·철학·종교·문학·예술·그 밖 7종류로 나눈다(`sentence-bank.js` 의 `QUOTE_KINDS`, 위쪽 종류가 먼저). 애니 명대사 목록에는 마추기(machugi.io) 「애니 명대사」 퀴즈의 문제 그림을, 영화·드라마 목록에는 「드라마 & 영화 속 명대사 보고 맞추기」 퀴즈의 문제 그림을 읽어 옮긴 대사도 있다(한 번 옮긴 것, 자동 갱신 아님). 갱신은 관리 화면 '문장' 또는 20일 스케줄. 빼고 싶은 문장은 `sentence-exclude.json` 에 적고 다시 갱신한다. 속담·명대사 결과 그림이 안 맞으면 같은 파일의 `images` 에 그 문장을 적고 다시 갱신한다. 다른 그림을 찾아 바꾸고, 버린 그림 주소는 `rejectedImages` 에 남아 다시 쓰지 않는다(`images` 는 갱신하면 비워짐).

## 확대 사진

「확대」 유형은 사진 한 점을 20배로 키워 보여 주고, 시간이 지나면 7배·3배·전체로 바뀐다(`zoom-bank.js` 의 `ZOOM_STEPS`). 단어 목록은 `zoom-bank.js` 의 `ZOOM_WORDS`(장르 동물·음식·물건·탈것·자연), 연예인은 위키데이터에서 한국 국적 배우·가수·방송인·코미디언을 위키 문서가 많은 순으로 받는다(세상을 떠난 사람·정치인 겸업은 뺌). 사진은 위키데이터 대표 그림(P18)의 위키미디어 공용 2560px 주소만 `zoom-pics.json` 에 둔다(파일은 저장하지 않음, 사진 라이선스는 각 파일 문서를 따른다). 대표 그림이 작으면(짧은 변 1200px 미만) 같은 항목의 공용 분류에서 품질·추천 사진을 먼저, 없으면 가장 큰 사진을 고른다. 갱신은 관리 화면 '확대 사진' 또는 20일 스케줄. 사진이 엉뚱한 단어는 `zoom-exclude.json` 의 `words`, 사람은 `people` 에 적고 다시 갱신한다. 검색 첫 결과가 다른 항목인 단어는 `ZOOM_IDS` 에 위키데이터 항목을 직접 적는다.

## 레시피

「레시피」 유형은 요리 재료를 먼저 보여 주고, 시간이 지나면 설명 문장 1·2줄, 마지막에 초성을 연다(`recipe-bank.js` 의 `RECIPE_STEPS`). 정답 공개 때는 대표 사진(없으면 생략)과 「출처 · 위키백과 「문서」 (CC BY-SA)」를 보여 준다. 스트리머 참여를 켜면 조작창에 정답 입력칸이 나오고 정답은 가려진다.

자료는 위키백과 한국어판 API(키 없음)로 받는다(`admin/refresh-recipes.mjs`).

- `RECIPE_ROOTS` 의 분류(나라별 요리·국민 음식·길거리 음식 등, 하위 분류 2단계)에서 문서를 모으고 최근 60일 조회수 순으로 2000개를 본다.
- 첫 문단에서 재료 낱말(`RECIPE_INGREDIENTS`)과 설명 문장을 뽑는다. 재료가 3개 안 되면 본문의 만드는 법 문장에서 더 찾고, 그래도 2개면 설명이 2줄 이상일 때만 낸다.
- 장르(한식·중식·일식·양식·세계)는 첫 문장과 문서 분류에 나온 나라 이름으로 정한다(`recipeGenreOf`).
- 본문은 고치지 않고 정답 이름(문서 제목·넘겨주기 이름)만 ○○ 로 가리며, 다른 이름·어원·연도 문장은 뺀다. 넘겨주기 이름은 채팅 정답으로도 받는다.
- 조회수 100 미만은 빼고, 대중적이지 않은 요리·음식이 아닌 것은 `recipe-exclude.json` 의 `words`, 장르를 바로잡을 요리는 `genres` 에 적는다. 결과는 `recipes.json`.
- 갱신은 관리 화면 '레시피' 또는 20일 스케줄. 거르는 규칙만 바꿔 볼 때는 `RECIPES_RAW=파일경로` 를 주면 받은 문서를 그 파일에 남겨 두고 다음엔 다시 받지 않는다.

## 상식

「상식」 유형은 문제 문장(「프랑스」의 수도는?)을 보여 주고, 시간이 지나면 글자 수 → 초성 힌트를 연다(`trivia-bank.js` 의 `TRIVIA_STEPS`). 정답 공개 때 명화 문제는 그림(위키미디어 공용 주소), 나머지는 문제 카드를 그대로 둔다. 스트리머 참여를 켜면 조작창에 정답 입력칸이 나온다.

자료는 위키데이터 질의(키 없음)로 만든다(`admin/refresh-trivia.mjs` → `trivia.json`).

- 수도·화폐: 지금 있는 나라 중 위키 문서가 많은 110개. 수도·화폐가 하나인 나라만, 답이 문제와 거의 같은 것(바티칸 시국·싱가포르)은 뺀다. 유로는 4개 나라만.
- 원소 기호: 원자 번호 36까지와 잘 알려진 원소(금·은·수은·우라늄 등).
- 명화·문학: 위키 문서가 많은 작품 → 그린 화가·쓴 작가. 공저, 제목이 같은 다른 작품, 종교 경전은 뺀다. 한국 소설은 따로 받는다.
- 다른 이름(도쿄/도쿄도, 위안)과 사람 이름의 뒤쪽(고흐, 다비드)도 정답으로 받는다. 같은 답(유로)이 여러 문제에 나와서 낸 문제는 문제 열쇠(key)로 기억한다.
- 난이도: 문제 속 두 항목(나라·수도, 그림·화가) 중 한국어 위키백과 최근 60일 조회수가 적은 쪽을 점수로, 갈래마다 아래 25%는 빼고 남은 것의 위쪽 절반은 「쉬움」, 나머지는 「어려움」(`assignTriviaLevels`). 낼 때는 쉬움 2 : 어려움 1 로 섞고, 문제 카드에 난이도를 보인다.
- 빼고 싶은 문제는 `trivia-exclude.json` 의 `titles`(명화·문학 제목)·`questions`(문제 문장)·`keys` 에 적는다. 갱신은 관리 화면 '상식' 또는 20일 스케줄.

## 밈

「밈」 유형은 밈 짤(사진)을 문제 카드 위에 띄우고, 시간이 지나면 글자 수 → 초성 힌트를 연다. 문제 카드는 상식과 같은 것을 쓴다(배지만 「😂 밈 · 2025」, 문제 문장은 「이 짤, 무슨 밈일까요?」). 문제는 `meme-bank.js` 의 `MEME_ITEMS`(83개, 갈래 옛날 밈·2025 밈·2026 밈): 마추기 아이오 밈 퀴즈(쉬운 유명 밈·밈 지박령·국내 밈 맞추기·2025 최신 릴스 밈 맞히기·2026 밈 맞추기)를 브라우저로 풀며 정답과 짤 그림 주소를 옮겼다. 그림은 내려받지 않고 마추기 그림 서버(images.machugi.io) 주소를 그대로 띄우므로, 올린 사람이 지우면 그 문제는 그림이 안 나온다. 답이 두 가지·영어·숫자·특수문자(문장부호 포함)·이모티콘·욕이 든 것, 같은 밈 중복, 사진에 답 글자가 보이는 것, 실제 사람 이름·별명, 비하·종교·폭력·정치 소재, 너무 긴 답은 뺐다. 자동 갱신은 없고 새 밈은 목록에 더한다.
